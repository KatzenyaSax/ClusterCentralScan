# M2SCAN 设计规格书

**日期：** 2026-05-10
**状态：** 草案
**目标：** 医学图像分割

---

## 1. 概述

M2SCAN（Multi-scale Mamba Scanning over Cluster Centers）是一种用于医学图像分割的 U-Net 变体。它将解码器中的卷积注意力替换为多尺度聚类中心扫描机制，并在编码器和解码器中统一使用 Mamba（SS2D/S6）实现高效的全局上下文建模。

### 1.1 核心思路

用 **MS-CCSM**（多尺度聚类中心扫描模块）替换 EMCAD 解码器中的 **MSCAM**（多尺度卷积注意力模块），同时用 **Mamba SS2D 编码器**替换 PVTv2 编码器。

| 组件 | EMCAD（基线） | M2SCAN（本文） |
|------|-------------|--------------|
| 编码器 | PVTv2 (Transformer) | SS2D Mamba（线性复杂度） |
| 解码器核心 | MSCAM（深度可分离卷积注意力） | MS-CCSM（聚类中心扫描） |
| 跳跃连接门控 | LGAG | LGAG（保留） |
| 上采样 | EUCB | EUCB（保留） |
| 多级损失 | 是 | 是（保留） |

### 1.2 创新点

1. **多尺度聚类中心扫描：** 将 CCSM 扩展到多尺度——不同解码器层级使用不同数量的聚类质心（K=[2,4,6,8]），实现从粗粒度语义到细粒度结构的层次化全局推理。

2. **全 Mamba 架构：** 编码器使用 SS2D（四方向选择性扫描）进行空间混合，解码器使用 S6 进行质心级全局推理。首个在 U-Net 编解码全链路统一使用 Mamba 空间建模的工作。

3. **高效解码器：** 保留 EMCAD 的 LGAG 门控和 EUCB 上采样，实现跳跃连接智能筛选和高效特征扩展。

## 2. 架构设计

### 2.1 整体网络结构

```
输入 (H×W×3)
    │
    ▼
┌────────────────────────────────────┐
│  Conv Stem (stride=4, 3→64)        │
└────────────────────────────────────┘
    │
    ├── Stage 1: SS2D Block ×2  ──── X1 (64ch, H/4)
    │       ↓ Patch Merge
    ├── Stage 2: SS2D Block ×2  ──── X2 (128ch, H/8)
    │       ↓ Patch Merge
    ├── Stage 3: SS2D Block ×8  ──── X3 (256ch, H/16)
    │       ↓ Patch Merge
    ├── Stage 4: SS2D Block ×2  ──── X4 (512ch, H/32)
    │
    ▼
┌────────────────────────────────────┐
│  Bottleneck: SS2D Block ×2 (512ch) │
└────────────────────────────────────┘
    │
    ▼  D4
┌────────────────────────────────────┐
│  解码器 Stage 4:                    │
│    EUCB ↑2× → LGAG(X4) →           │
│    MS-CCSM(K=2) → SegHead → p4     │
│                    ↓                │
│  解码器 Stage 3:                    │
│    EUCB ↑2× → LGAG(X3) →           │
│    MS-CCSM(K=4) → SegHead → p3     │
│                    ↓                │
│  解码器 Stage 2:                    │
│    EUCB ↑2× → LGAG(X2) →           │
│    MS-CCSM(K=6) → SegHead → p2     │
│                    ↓                │
│  解码器 Stage 1:                    │
│    EUCB ↑2× → LGAG(X1) →           │
│    MS-CCSM(K=8) → SegHead → p1     │
└────────────────────────────────────┘
    │
    ▼
最终分割图 (H×W×#classes)
```

### 2.2 编码器：Mamba SS2D 模块

每个 SS2D Block 由以下组成：
- LayerNorm → SS2D（四方向选择性扫描）→ LayerNorm → FFN（MLP）

四方向扫描将 2D 特征图按 4 条路径展开为序列（左上→右下、右下→左上、右上→左下、左下→右上），对每条路径分别应用 Mamba S6，然后合并。这在线性复杂度下提供了全局感受野。

- 通道数：64 → 128 → 256 → 512
- Block 分布：[2, 2, 8, 2]（Stage 3 最深，因为 H/16 分辨率是感受野与计算量的最优平衡点）
- 下采样：Patch Merge（2×2→1，通道翻倍）

### 2.3 解码器：MS-CCSM + EMCAD 组件

每个解码器层级：EUCB → LGAG → MS-CCSM(K) → SegHead

**保留的 EMCAD 组件：**
- **EUCB（高效上卷积模块）：** Upsample(×2) → 3×3 DWConv → BN → ReLU → 1×1 Conv。高效上采样，用深度可分离卷积替代标准 3×3 卷积。
- **LGAG（大核分组注意力门控）：** 对跳跃连接特征进行大核分组注意力筛选，过滤噪声后再与上采样后的解码器特征融合。
- **SegHead（分割头）：** 1×1 卷积，将特征通道映射到类别数。
- **多级损失：** L = Σ L(p_i) + L(Σ p_i)，沿用 EMCAD 的 MUTATION 组合损失。

**替换 MSCAM 的模块：**
- **MS-CCSM(K)：** CCSM（K 个质心）+ SCFM 并行运行，输出融合后的特征图。

### 2.4 MS-CCSM 内部结构

```
F_in ──┬──► CCSM(K) ──► 全局上下文 ──┐
       │                              ├──► 融合 ──► F_out
       └──► SCFM ──────► 细节特征 ───┘
```

- **CCSM(K)：** 将 H×W 个像素特征通过相似度软分配提炼为 K 个聚类质心；仅在这 K 个质心上运行 Mamba S6 进行全局推理；将质心级的全局上下文通过可学习的相似度分布扩散回所有像素。K 控制聚类粒度。
- **SCFM（空间-通道特征调制器）：** 并行的空间注意力 + 通道注意力纯卷积路径，保留聚类过程中可能丢失的高频细节（纹理、边界）。

### 2.5 多尺度 K 策略

| 解码器层级 | 分辨率（相对输入） | K | 含义 |
|-----------|-------------------|---|------|
| Stage 4 | H/16 | 2 | 粗粒度：前景 vs 背景 |
| Stage 3 | H/8 | 4 | 中等粒度 |
| Stage 2 | H/4 | 6 | 较细粒度 |
| Stage 1 | H/2 | 8 | 最细粒度：小结构、边界 |

分辨率越高→需要更多质心来表示更丰富的空间变化。

## 3. 实现计划

### 3.1 文件结构

```
prcv2026/
├── models/
│   ├── __init__.py
│   ├── encoder.py          # Mamba SS2D 编码器 + 瓶颈层
│   ├── decoder.py          # 带 MS-CCSM 的 EMCAD 风格解码器
│   ├── ms_ccsm.py          # MS-CCSM 模块（CCSM + SCFM）
│   ├── ccsman.py           # 聚类中心扫描模块
│   ├── scfm.py             # 空间-通道特征调制器
│   ├── lgag.py             # 大核分组注意力门控
│   ├── eucb.py             # 高效上卷积模块
│   └── m2scan.py           # 完整模型组装
├── configs/
│   └── m2scan.yaml         # 模型超参数
├── train.py                # 训练入口
├── scripts/
│   └── draw_architecture.py
└── docs/superpowers/specs/
    ├── 2026-05-10-M2SCAN-design.md
    └── 2026-05-10-M2SCAN-design-zh.md
```

### 3.2 关键超参数

| 参数 | 值 | 说明 |
|------|----|------|
| 编码器 Blocks | [2, 2, 8, 2] | 每个 Stage 的 SS2D Block 数量 |
| 通道数 | [64, 128, 256, 512] | 各 Stage 通道数 |
| K 值 | Stage1→Stage4: [8,6,4,2] | 高分辨率=多质心，低分辨率=少质心 |
| MLP 扩展因子 | 4 | SS2D Block 内部 |
| S6 d_state | 16 | Mamba 状态空间维度 |
| 预估参数量 | ~10–12M | vs EMCAD-B2 的 26.8M |

### 3.3 依赖

- PyTorch >= 2.0
- mamba-ssm（选择性扫描 CUDA 算子）或纯 PyTorch SS2D 回退实现
- timm（可选，用于训练工具）

### 3.4 训练策略

沿用 EMCAD 的训练协议：
- 优化器：AdamW，lr=1e-4，weight_decay=1e-4
- 训练轮数：200（二分类），300–400（多器官）
- Batch size：16（二分类），6–12（多器官）
- 输入尺寸：352×352（二分类），224×224（多器官）
- 多尺度训练：{0.75, 1.0, 1.25}
- 损失函数：加权 BCE + 加权 IoU（二分类）；交叉熵 + Dice（多类别）
- 梯度裁剪：0.5

### 3.5 评估方案

- 二分类分割：10 个数据集（息肉×5、皮肤病变×2、细胞×2、乳腺癌）
- 多器官分割：Synapse、ACDC
- 指标：DICE、HD95、mIoU
- 效率：参数量、FLOPs（在 224×224 和 256×256 分辨率下测量）

## 4. 风险与缓解

| 风险 | 缓解措施 |
|------|---------|
| SS2D CUDA 算子不可用 | 实现纯 PyTorch 回退：4 方向 unfold + scan |
| CCSM 在 K > H×W 时退化 | 保护逻辑：K = min(K, sqrt(H×W)) |
| Mamba 训练不稳定 | 沿用 VMamba 的学习率和 warmup 策略，梯度裁剪 |
| SCFM 增加冗余参数 | 通过消融实验验证必要性；可设为可选项 |

## 5. 消融实验计划

1. **K 值消融：** 对比 [2,4,6,8] vs [4,4,4,4]（单尺度 CCSM）vs [1,2,4,8]
2. **SCFM 消融：** 有 vs 无（验证细节补偿作用）
3. **LGAG 消融：** 有 vs 无（验证跳跃门控贡献）
4. **编码器深度：** [2,2,8,2] vs [2,2,4,2] vs [2,2,12,2]
5. **vs EMCAD 基线：** 相同编码器下，对比 MSCAM vs MS-CCSM 解码器
