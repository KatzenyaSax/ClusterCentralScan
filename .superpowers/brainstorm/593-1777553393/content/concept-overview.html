聚类中心扫描 vs 传统光栅扫描

核心思想：为什么"扫描簇"比"扫描像素"更高效？

传统方法：像素级光栅扫描 (Raster Scan)
图像 → 逐行扫描每个像素 → 1D序列
行0: p0 p1 p2 p3 p4 ... (从左到右)
行1: p5 p6 p7 p8 p9 ...
行2: p10 p11 p12 p13 p14 ...
最终序列: [p0, p1, p2, p3, p4, p5, p6, p7, p8, ...]
长度 = H × W（所有像素）
❌ 相邻像素可能语义无关却被排在一起
❌ 语义相近的像素可能被远距离分开
❌ 序列长度过长 → 计算量 O(N²)
论文方法：聚类中心扫描 (Cluster-Centric Scan)
图像 → 聚类 → 簇中心排序 → 1D序列
簇A (天空): p2,p3,p7,p12,p17... → 中心 C₀
簇B (草地): p1,p4,p6,p9,p11... → 中心 C₁
簇C (建筑): p0,p5,p8,p10,p14... → 中心 C₂
最终序列: [C₀, C₁, C₂] → 每个中心代表一组像素
长度 = K（簇的数量） << N
✅ 按语义分组，相关像素聚合在一起
✅ 聚类中心代表整个簇的语义特征
✅ 序列大幅缩短 → 计算量降为 O(K²)

直觉类比

📖 传统扫描 = 逐字阅读

一个字一个字地读，即使相邻的字意思相同。读到"蓝蓝蓝蓝天天天..."，明明可以总结为"蓝天"两个字。

🧠 聚类扫描 = 先总结再阅读

先把相似的像素归为一组（"这些都属于天空"），然后用组的代表（中心）来组织序列。效率高得多，语义也更清晰。
